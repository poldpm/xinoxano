# Xino-Xano · Fitxes per imprimir

Eina de Vedruna Escorial Vic perquè el professorat prepari fitxes de català i mates (1r a 6è) per imprimir o desar en PDF, amb un full de solucions per a l'adult.

- No demana cap compte ni cap dada. El que es tria només es guarda al navegador de qui la fa servir.
- Els exercicis surten del banc de Xino-Xano, preparat amb ajuda d'IA i revisat.
- Aquesta és una versió provisional, fins que l'app completa tingui servidor propi.

Les tipografies (Fira Sans, Andika i Lexend) es distribueixen amb la llicència SIL Open Font License 1.1: vegeu els fitxers `assets/fonts/OFL-*.txt`.
